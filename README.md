## Descrição do projeto
Este projeto é uma aplicação de forum, onde os usuários podem realizar perguntas com anexos e as responder com anexos, o projeto também inclui notificações, para notificar um usuário quando ocorrer uma resposta na sua pergunta.
Neste projeto utilizei os conceitos de DDD e clean arquiteture para desenvolver o forum.
